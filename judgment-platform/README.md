# ⚖️ COATS — Frontend Portal (React 19 + Vite)

This is the frontend user interface for **COATS (Court Order Action & Tracking System)**.

For full project architecture, complete tech stack, backend guides, and API documentation, please refer to the [Root README](../README.md).

---

## 🚀 Quick Setup

```bash
# 1. Install dependencies
npm install

# 2. Start local development server
npm run dev
```

The app will be available at `http://localhost:5173`.

## 📦 Key Libraries & Technologies
- **React 19**: Component system and state management
- **Vite**: Build tool and hot module replacement
- **Server-Sent Events (SSE)**: Real-time processing progress streaming
- **Custom Judicial Theme**: Gold and deep slate judicial palette with accessibility support
