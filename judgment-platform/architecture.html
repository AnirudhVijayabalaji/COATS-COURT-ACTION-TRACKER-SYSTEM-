COATS — Architecture & Workflow

Court Order Action & Tracking System · Technical Overview

📋   End-to-End Workflow
📄
Step 01
PDF Upload
User uploads court judgment PDF via React dashboard
🔍
Step 02
Text Extraction
pdfplumber extracts text; pytesseract OCR handles scanned PDFs
🧠
Step 03
AI Analysis
LangChain + Groq (Llama 3.3) extracts structured JSON from legal text
🗄️
Step 04
Data Storage
Structured data saved to SQLite (local) or Supabase PostgreSQL (cloud)
📊
Step 05
Dashboard View
React renders Workflow, Evidence, Timeline & Audit tabs
✅
Step 06
Human Verification
Legal Reviewer approves / rejects each AI-generated step
